個人介紹網站｜上傳說明
====================

檔案：
- index.html：網站內容
- style.css：視覺樣式與響應式版面
- script.js：手機選單、明暗模式與年份

使用方法：
1. 將 ZIP 解壓縮。
2. 將 index.html、style.css、script.js 三個檔案一起上傳到網站目錄。
3. 若放在 public_html/profile/，網址通常是 https://你的網域/profile/
4. 若要作為網域首頁，將三個檔案放入 public_html/（請先備份原有首頁）。
5. 網站不需要資料庫、PHP 或外部套件。

修改方式：
- 個人介紹、標題、作品領域：編輯 index.html。
- 色彩、字體、排版：編輯 style.css。
- 功能：編輯 script.js。
- 作品圖片目前是 CSS 生成的示意視覺，不是實際作品照片。
- 聯絡區目前連至 https://www.multicore.com，請依需要增補電子郵件。

建議：正式公開前確認姓名、介紹、連結與內容是否符合需求。
